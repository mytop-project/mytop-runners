# Changelog

## 0.1.0

- `launch`: reading a program's architecture from its ELF header, the command that runs it through FEX or Box64
  without root, and how a Ren'Py game's own Linux launcher is started for the binaries it ships
  (mytop-project/tracker#962). Takes mytop-containers 0.1.0 (`arch`) as `vendor/mytop-containers`.

- The repository, holding Wine and Proton builds, emulators, launch templates as data.
